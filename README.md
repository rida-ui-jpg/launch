# launch
Launch — Fantasy Startup League
A browser-based fantasy game where you draft real early-stage startups, earn points when they hit milestones, and compete against friends in a league.
Built with HTML, CSS, and JavaScript. No frameworks, no backend — fully client-side.
How to play:

Create or join a league with a code
Draft 10 startups from a pool of 20 real companies
Watch your score update live as milestones fire
Climb the leaderboard
